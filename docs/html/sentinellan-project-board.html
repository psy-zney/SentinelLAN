02 / Week 1 flow

Login → refresh → logout

Luồng browser/Employee đã được chạy bằng Chromium thật. Nhánh lưu session PostgreSQL có code và CI gate, nhưng vẫn là đường đen tại máy này cho tới khi có PostgreSQL runtime.

01 · DONELoginOrganization code + email + password. API trả access/refresh HttpOnly cookie.
02 · DONERole routingAdmin/Technician → dashboard; Employee → my-device.
03 · DONESession guardMở URL trực tiếp vẫn đọc session và chặn/redirect sai role.
04 · DONEAssigned deviceOrganizationId + AssignedUserId; tải device, policy và action.
05 · DONERefreshCSRF header, rotate refresh token, thay cả hai cookie.
06 · DONELogoutRevoke refresh session, xóa access + refresh cookie.

05 / Operator guide

Test · debug · dùng · config

Hướng dẫn ngắn để một người mới có thể chạy đúng luồng mà không đưa secret vào repository hoặc vô tình bật hành vi thiết bị thật.

Chạy kiểm tra

dotnet restore SentinelLAN.slnx
dotnet format SentinelLAN.slnx --verify-no-changes --no-restore
dotnet build SentinelLAN.slnx --configuration Release --no-restore
dotnet test SentinelLAN.slnx --configuration Release --no-build
npm.cmd run lint && npm.cmd run typecheck && npm.cmd test && npm.cmd run build
npx.cmd playwright install chromium npm.cmd run test:e2e

PostgreSQL-backed test: đặt ConnectionStrings__SentinelLAN trỏ tới database test riêng rồi chạy integration test. Test factory sẽ assert provider Npgsql. Không dùng database production.

Chẩn đoán theo HTTP/status

401 · Chưa xác thực

Browser: kiểm tra API URL, access/refresh cookie và CORS credential. Agent: phải có cả X-SentinelLAN-Device-Id và X-SentinelLAN-Device-Secret; credential phải chưa revoke.

403 · Đúng danh tính, sai policy

Đối chiếu role: Admin-only cho users/audit; Admin hoặc Technician cho operations; Employee-only cho my-device; Agent-only cho transport.

404 · Không thấy device

Đây có thể là chủ ý chống BOLA. Kiểm tra OrganizationId và, với Employee, AssignedUserId. Không bỏ scope để “sửa nhanh”.

400 · Anti-CSRF header required

Request thay đổi trạng thái bằng cookie phải có X-SentinelLAN-CSRF: 1. Typed API client đã tự thêm header này.

503 · Database unavailable

Kiểm tra connection string, PostgreSQL health, migration và /health/ready. Không fallback InMemory ngoài Development/test.

Playwright không khởi động

Kiểm tra port 3000/8080, chạy npx playwright install chromium, và dừng server cũ nếu cấu hình không thể reuse.
