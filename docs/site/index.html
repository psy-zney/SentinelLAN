Quản lý thiết bị trong mạng nội bộ

Một luồng rõ ràng cho quản trị viên, nhân viên và từng máy trạm.

SentinelLAN kết nối Agent trên thiết bị đã được tổ chức cho phép với API trên VPS. Quản trị viên cấp quyền và theo dõi trạng thái; nhân viên xem thiết bị được gán và báo sự cố. Hệ thống thu thập chỉ số kỹ thuật như CPU, RAM, ổ đĩa và nhịp kết nối.

Cách hoạt động

Từ đăng ký tới xử lý sự cố

01

Đăng ký thiết bị

Admin tạo token một lần. Agent dùng HTTPS để đăng ký và lưu định danh được bảo vệ trên máy.

02

Gửi trạng thái

Agent gửi heartbeat và chỉ số kỹ thuật định kỳ; khi mất mạng, telemetry chờ gửi lại trong giới hạn.

03

Phân quyền

Admin gán thiết bị cho nhân viên. Web hiển thị theo vai trò; mobile hiện phục vụ nhân viên.

04

Xử lý và kiểm toán

Nhân viên báo sự cố; thao tác nhạy cảm cần quyền phù hợp và được ghi vào nhật ký kiểm toán.

SentinelLAN hiện không cung cấp packet sniffing, remote desktop hay khóa máy thật trong Agent mặc định. Xem sơ đồ chủ thể, bảo mật, truyền tệp và database.

Hướng dẫn nhanh

Cài Windows bằng MSI

  1. Admin triển khai VPS và xác nhận API có chứng chỉ HTTPS hợp lệ.
  2. Admin tạo enrollment token một lần trên dashboard cho máy được phép.
  3. Tải MSI từ Release, kiểm tra SHA-256 rồi cài với quyền Administrator.
  4. Tải script cấu hình cùng Release; mở PowerShell Administrator và chạy lệnh bên dưới. Script hỏi token qua prompt, bật service và xóa token khỏi file cấu hình sau khi đăng ký.
  5. Kiểm tra service SentinelLANAgent và heartbeat trong dashboard.

PowerShell · chạy tại thư mục có script

./configure-windows-agent.ps1 -ServerUrl 'https://sentinel.example.com'
Lấy script cấu hình từ Release →

Muốn cài im lặng qua công cụ quản trị?

msiexec /i SentinelLAN.Agent.msi /qn
Cấu hình URL và token bằng script riêng trên từng máy; không đặt token trên dòng lệnh MSI.

Release công khai có phù hợp?

Có, cho bộ cài và mã triển khai không chứa bí mật. GitHub Release không mang theo .env, dữ liệu PostgreSQL, chứng chỉ hoặc khóa của VPS. Người vận hành tự cấp các giá trị này theo hướng dẫn triển khai VPS. Mỗi máy trạm cần token đăng ký riêng do admin tạo trong hệ thống đang chạy.
