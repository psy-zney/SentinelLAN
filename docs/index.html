3 Trụ Cột Chiến Lược

SentinelLAN được cấu trúc để linh hoạt đáp ứng mọi quy mô triển khai của doanh nghiệp và cộng đồng IT.

🏢

1. Tự Host Nội Bộ (Self-Hosted)

Dành cho doanh nghiệp, cơ quan, trường học muốn kiểm soát 100% dữ liệu trên máy chủ văn phòng mà không phụ thuộc Internet.

  • Triển khai 1 lệnh qua Docker Compose stack.
  • Dữ liệu lưu trữ nội bộ trên PostgreSQL cục bộ.
  • Agent kết nối trực tiếp trong mạng LAN / Wi-Fi.
  • Miễn phí, không lo rò rỉ thông tin ra Internet.

🌐

2. Mã Nguồn Mở (Open-Source)

Cung cấp mã nguồn sạch, kiến trúc chuẩn Modular Monolith / Clean Architecture để cộng đồng dễ dàng clone và mở rộng.

  • Backend .NET 10 (C# 14) & Frontend Next.js 16.
  • Ranh giới phân tầng Domain, Application, Infra rõ ràng.
  • Quy chuẩn kiểm thử tự động xUnit, Vitest, Playwright.
  • Không dính líu đến bản quyền độc quyền hay vendor lock-in.
Xem hướng dẫn đóng góp Open Source →
☁️

3. Cloud VPS & Multi-Tenant SaaS

Dành cho việc kinh doanh dịch vụ quản lý đa công ty (SaaS) và quản trị máy chủ Cloud Linux qua kết nối SSH an toàn.

  • Cô lập đa tổ chức (Multi-Tenant) 4 lớp nghiêm ngặt.
  • Quản trị VPS từ xa bằng SSH Private Key + IPv4.
  • Kho bảo vệ Private Key mã hóa bằng AES-256-GCM Vault.
  • Thu thập CPU, RAM, Disk, Docker Container từ xa.

Workflows

Sơ Đồ Luồng Kỹ Thuật (System Workflows)

Khám phá trực quan từng bước giao tiếp giữa Client, Server, Database và Endpoint Agent.

Quy trình Bắt tay An toàn (Enrollment Handshake)

Cơ chế xác thực một lần (Single-use Token), sinh cặp khóa phần cứng và kích hoạt Agent qua Windows Service.

01
Admin Cấp Token
IT bấm cấp Token trên Web Dashboard. Backend sinh ngẫu nhiên 32 byte qua CSPRNG và chỉ lưu bản băm SHA-256 vào Database.
POST /api/v1/enrollment-tokens
02
Agent Bắt Tay Đăng Ký
Agent trên máy nhân viên gửi HTTP POST kèm Token thô và thông tin phần cứng (Hostname, OS Version).
POST /api/v1/agent/enroll
03
Hủy Token & Cấp Khóa Máy
Server kiểm tra Token hợp lệ -> Hủy Token nguyên tử (không thể tái sử dụng) -> Tạo Device ID + Device Secret riêng cho máy đó.
Atomic Transaction Commit
04
Lưu DPAPI & Bật Đèn Xanh
Agent lưu khóa vào Windows DPAPI phần cứng. Server phát sự kiện SignalR giúp máy tính hiện đèn XANH Online tức thì trên Dashboard.
SignalR: device-status (Online)

Thu Thập Telemetry & Cập Nhật Realtime

Giám sát thông số kỹ thuật tối thiểu (CPU, RAM, Disk) định kỳ 30s với cơ chế chống mất mát gói tin.

01
Thu Thập Kỹ Thuật
Agent Worker định kỳ đo % CPU, % RAM, % Disk. Tuyệt đối không đọc file hay chụp ảnh màn hình.
ITelemetryCollector.Collect()
02
Gửi Heartbeat Xác Thực
Gửi payload kèm IdempotencyKey qua header X-SentinelLAN-Device-Id và Secret. Chống ghi trùng lặp dữ liệu.
POST /api/v1/agent/heartbeat
03
Lưu TelemetrySnapshots
Backend lưu trữ lịch sử sử dụng phần cứng theo thời gian, tính toán trạng thái Online / Offline tự động.
PostgreSQL: TelemetrySnapshots
04
Broadcast WebSocket
Server bắn WebSocket tới riêng phòng của Tenant đó. Biểu đồ trên màn hình Dashboard cập nhật ngay lập tức.
SignalR: TenantGroup(orgId)

Lệnh Điều Khiển Ký Số (Safe Simulated Commands)

Mỗi lệnh điều khiển đều bắt buộc có lý do, xác nhận, thời hạn ngắn, kèm chữ ký số HMAC-SHA256 10 tham số.

01
Admin Tạo Lệnh
Chọn lệnh allow-list (SimulateLock, RestartService...), điền lý do và xác nhận. Thời hạn hiệu lực 30–900 giây.
POST /api/v1/commands
02
Ký Mật Mã 10 Tham Số
Server ký HMAC-SHA256 gồm [Id, OrgId, DeviceId, UserId, Type, Reason, IssuedAt, ExpiresAt, Nonce, Parameter]. Lưu trạng thái Pending.
HmacCommandSigner.Sign()
03
Agent Polling & Xác Thực
Agent kiểm tra chữ ký khớp, kiểm tra thời hạn và kiểm tra Nonce chống Replay Attack trước khi nhận lệnh.
CommandVerifier.TryAccept()
04
Thực Thi Mô Phỏng An Toàn
Lệnh chạy ở chế độ mô phỏng an toàn (0 P/Invoke, 0 phá hoại hệ điều hành). Agent gửi lại Receipt kết quả cho Server.
SafeCommandExecutor.Execute()

Quản Trị Cloud VPS qua SSH (Agentless Node Management)

Cơ chế giám sát máy chủ Linux từ xa bằng IPv4 và OpenSSH Private Key mã hóa AES-256-GCM.

01
Nhập IPv4 & Private Key
Admin nhập IPv4 và SSH Private Key của VPS từ giao diện web.
UI: Cloud Nodes Modal
02
Mã Hóa Vault AES-256
Server mã hóa Private Key bằng khóa chủ MASTER_VAULT_KEY trước khi lưu vào Database. Tuyệt đối không lưu plain-text.
AES-256-GCM Vault Store
03
SSH.NET Handshake
Backend giải mã Key trong RAM tạm thời, mở kết nối SSH port 22 tới VPS đích qua thư viện SSH.NET.
Renci.SshNet.SshClient
04
Thu Thập Metrics & Docker
Chạy các lệnh an toàn read-only: free -m, df -h, docker ps -> Parse dữ liệu hiển thị biểu đồ lên Dashboard.
Telemetry & Container Live List

Phân Công Thiết Bị & Minh Bạch Riêng Tư (Privacy-First)

Mỗi nhân viên chỉ được gán tối đa 1 máy hoạt động; nhân viên được quyền xem nhật ký hành động của IT trên máy mình.

01
Ràng Buộc 1 Thiết Bị / Người
Được bảo vệ kép: Validation nghiệp vụ + PostgreSQL Partial Unique Index (AssignedUserId IS NOT NULL AND IsRevoked = FALSE).
PUT /api/v1/devices/{id}/assignment
02
Thu Hồi Thiết Bị (Revoke)
Hủy credential và xóa phân công nguyên tử trong 1 SaveChanges. Agent cũ khi gửi request tiếp theo sẽ bị từ chối 401.
POST /api/v1/devices/{id}/revoke
03
My Device Transparency View
Nhân viên đăng nhập vào /my-device sẽ thấy chính xác chính sách đang áp dụng và 20 thao tác gần nhất của IT trên máy mình.
GET /api/v1/my-device
04
Audit Log Bất Biến
Toàn bộ thao tác ghi nhận vào AuditLogs. Tầng EF Core tự động ném ngoại lệ chặn đứng mọi lệnh UPDATE hoặc DELETE audit.
Append-Only EF Interceptor

Cam Kết Bảo Vệ Quyền Riêng Tư (Privacy-First)

SentinelLAN bảo vệ an toàn kỹ thuật, kiên quyết nói không với hành vi gián điệp:

❌ Những gì TUYỆT ĐỐI KHÔNG làm

  • Không ghi phím gõ (No Keylogger).
  • Không chụp hay quay lén màn hình.
  • Không kích hoạt camera hoặc microphone.
  • Không đọc trộm file cá nhân hoặc lịch sử web.

✅ Những gì hệ thống giám sát

  • Chỉ số tải phần cứng: % CPU, % RAM, % Ổ đĩa.
  • Trạng thái kết nối: Online / Offline, thời gian Heartbeat.
  • Phiên bản hệ điều hành và phiên bản Agent.
  • Nhân viên có trang /my-device minh bạch 100%.
