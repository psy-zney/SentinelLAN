## 1. Giới thiệu tổng quan (Release Highlights)

SentinelLAN v1.0.0 là giải pháp toàn diện kết hợp giữa **Quản trị an toàn thiết bị đầu cuối văn phòng (Zero-Trust Endpoint Management)** và **Quản trị máy chủ đám mây từ xa (Cloud VPS Node Governance)**. Hệ thống được kiến trúc theo chuẩn Clean Architecture / Modular Monolith, thiết kế Outbound-only và Zero-Knowledge Vault nhằm đảm bảo tính bảo mật, minh bạch và hiệu năng cao nhất.

## 2. Các Tính Năng Nổi Bật Trong Bản Phát Hành v1.0.0

### ☁️ 1. Quản trị Cloud VPS từ xa (Agentless SSH Management)
* **Zero-Knowledge Private Key Vault:** Mã hóa OpenSSH Private Key bằng thuật toán `AES-256-GCM` sử dụng khóa bí mật `SENTINELLAN_SERVER_VAULT_KEY`. Khóa chỉ được giải mã tức thời trong RAM khi thực thi lệnh và hủy ngay khi ngắt kết nối. Tuyệt đối không bao giờ trả khóa về qua API.
* **Giám sát tài nguyên thời gian thực:** Định kỳ thu thập các chỉ số kỹ thuật gồm CPU load, RAM sử dụng (`free -m`), Dung lượng ổ đĩa (`df -k /`), số lượng Docker containers đang chạy và thời gian hoạt động (Uptime).
* **Tự phục hồi dịch vụ an toàn (Allow-Listed Service Recovery):** Hỗ trợ khởi động lại các dịch vụ bị treo hoặc lỗi (Nginx, Docker, Sentinellan-Agent) trực tiếp từ Dashboard có ghi nhận lý do và kiểm toán (Audit Trail) bất biến.

### 🛡️ 2. Quản trị Endpoint Không Xâm Phạm Quyền Riêng Tư (Privacy-First Endpoint Governance)
* **Least-Privileged Agent:** Agent chạy dưới dạng Windows Service hoặc Linux systemd daemon với quyền người dùng tiêu chuẩn, không đòi hỏi Administrator liên tục.
* **Minh bạch thông tin (Employee Transparency View):** Nhân viên có thể xem minh bạch mọi thông số công ty đang theo dõi trên máy tính của mình tại `/my-device`. Cam kết không quay quét màn hình, không theo dõi phím gõ (keylogger), không thu thập tài liệu cá nhân.
* **Safe Simulated Commands:** Các lệnh can thiệp (khóa máy, cách ly mạng) mặc định chạy ở chế độ mô phỏng an toàn; chỉ kích hoạt hành vi thật trong môi trường lab được ủy quyền rõ ràng.

### 🏢 3. Kiến Trúc Đa Tổ Chức (Multi-Tenant SaaS) & Xác Thực Nâng Cao
* **Cô lập Tenant tuyệt đối:** Mỗi tổ chức có ranh giới dữ liệu độc lập (`ITenantOwned`), truy vấn EF Core được bảo vệ bằng Global Query Filters.
* **Bảo mật phiên đăng nhập:** HttpOnly cookie kết hợp luồng xoay vòng token (Rotating Refresh Token), CSRF prevention header bắt buộc cho mọi yêu cầu thay đổi trạng thái, và Rate Limiting chống tấn công Brute-force.
* **Realtime Push qua SignalR:** Cập nhật trạng thái thiết bị trực tuyến/ngoại tuyến tức thì đến dashboard quản trị viên.

## 3. Hướng Dẫn Triển Khai Nhanh 1-Click Trên Cloud VPS

### Bước 1: Chuẩn bị máy chủ
Thuê một máy chủ VPS (Ubuntu 22.04/24.04 hoặc Debian 12, tối thiểu 2 vCPU, 4GB RAM) và trỏ domain về IP của VPS.

### Bước 2: Chạy script cài đặt tự động
```bash
git clone https://github.com/psy-zney/SentinelLAN.git
cd SentinelLAN/deploy/vps
sudo bash setup-vps.sh
```
Script sẽ tự động:
1. Cài đặt Docker Engine và Docker Compose Plugin chính hãng.
2. Tạo cấu hình mã hóa bảo mật ngẫu nhiên trong `.env`.
3. Build và khởi chạy các container (API .NET 10, Web Next.js 16, PostgreSQL 18, Reverse Proxy Nginx).
4. Kiểm tra sức khỏe hệ thống (`/health/ready`) và in thông tin quản trị ra màn hình.

## 4. Hướng Dẫn Cài Đặt Agent Trên Thiết Bị Quản Lý

### Cài đặt trên Windows (PowerShell với quyền Administrator):
```powershell
.\deploy\agent\install-windows-agent.ps1 -ServerUrl "https://api.yourdomain.com" -EnrollToken "YOUR_ENROLLMENT_TOKEN"
```

### Cài đặt trên Linux VPS / Container (Bash với quyền Root):
```bash
sudo bash ./deploy/agent/install-linux-agent.sh --server "https://api.yourdomain.com" --token "YOUR_ENROLLMENT_TOKEN"
```
