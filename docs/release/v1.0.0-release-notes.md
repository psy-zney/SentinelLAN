# SentinelLAN v1.0.0 — ghi chú bản phát hành

Ngày gắn tag: 2026-09-21. Tài liệu này ghi lại phạm vi của tag `v1.0.0`; cách cài đặt và giới hạn của mã hiện tại nằm trong [README](../../README.md). Không xem tag hoặc kết quả unit test là xác nhận hệ thống đã sẵn sàng cho mọi môi trường Production.

## Chức năng

- Quản lý tài khoản, phiên web, thiết bị được gán, telemetry kỹ thuật, alert/incident và audit theo tenant.
- Agent Windows/Linux đăng ký bằng token một lần, gửi heartbeat và nhận lệnh có chữ ký. Các lệnh khóa máy, cô lập mạng và restart service qua Agent chỉ trả kết quả mô phỏng.
- Chức năng mở rộng VPS qua SSH từ API: khóa riêng được mã hóa bằng server vault key; phải pin SSH host-key fingerprint. Restart dịch vụ allow-list là thao tác thật và cần quyền, lý do, xác nhận cùng nonce. Luồng này không thuộc nghiệm thu lõi endpoint.
- Web dùng cookie HttpOnly và CSRF header; Employee chỉ xem thiết bị được gán.

## Triển khai và giới hạn

Làm theo [runbook VPS](../deployment/saas-vps-guide.md) hoặc [runbook LAN](../deployment/self-hosted-guide.md). Chuẩn bị Docker Compose, DNS và chứng chỉ TLS trước khi chạy setup. Script không tự cài Docker, không tự cấp chứng chỉ và không in mật khẩu bootstrap ra terminal. Installer Agent hỏi token tương tác; không truyền token trên dòng lệnh.

Tenant scope hiện là kiểm tra và truy vấn tường minh, chưa có database row-level security. Server vault key không phải mô hình zero knowledge vì server giải mã khóa SSH khi cần kết nối. Audit được bảo vệ ở tầng ứng dụng, chưa có WORM. Kiểm thử PostgreSQL thật, TLS, SSH, backup/restore và Agent trên OS đích phải được ghi nhận riêng cho từng đợt triển khai. Xem [threat model](../security/threat-model.md) và [kịch bản nghiệm thu](../demo/demo-script.md).
